From January through April 2026, I worked as a software engineer intern on a backend team at CIBC, contributing to Java/Spring Boot microservices running on Azure.

Day-to-day, I participated in Agile standups, collaborated in a Git-based workflow, and shipped backward-compatible changes to production services. Broadly, I got to:
- Extend existing microservices with new functionality while preserving compatibility for downstream consumers.
- Author the system design for an integration with [Canada's Real-Time Rail](https://www.payments.ca/systems-services/payment-systems/real-time-rail-payment-system), the new national real-time payments system being delivered by Payments Canada.
- Design orchestration logic for a couple of client-facing and internal workflows.
- Write a platform reference doc covering service architecture, environments, and day-2 operations, which got adopted into the team's onboarding material.

Read more about how Canada's payments system is being modernized over at [Payments Canada](https://www.payments.ca/).
